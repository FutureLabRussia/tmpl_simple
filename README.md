

# Исходный код шабона Simple для CMS Joomla v5/6 


Обучающий курс по разработке шаблонов для Joomla 5/6. разработан на основе внутренних инструкций для сотрудников  и публикуется на сайте ООО "Лаборатория Будущего".

Каждая часть руководства имеет результатом рабочий шаблон, который можно установить в систему 
для тестирования, описанных в этой части руководства возможностей.
